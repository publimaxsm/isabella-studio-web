# Isabella Studio · Tu universo de belleza

Tienda online luxury de maquillaje, skincare, cabello, perfumes y herramientas — Coro, Estado Falcón.

- **Stack:** Next.js 16 · TypeScript · Tailwind CSS 4 · (Supabase en la siguiente fase)
- **Estructura completa y pendientes:** [`docs/ESTRUCTURA.md`](docs/ESTRUCTURA.md)
- **Modelo de datos:** [`supabase/schema.sql`](supabase/schema.sql)

```bash
npm install
npm run dev      # http://localhost:3000
```

> Los productos, marcas, reseñas, datos de pago y tasa de cambio actuales son **de demostración**.
